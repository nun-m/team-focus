# Team Focus

チーム用のタスク管理ツール。案件・タスクに担当者を割り振り、メンバーごとの稼働と空きを確認できる。

自分たちのPCやサーバーに置いて使うWebアプリ。1台でサーバーを動かし、チームのメンバーはブラウザーで開いて共有する。データはサーバーを動かしている1台の中にだけ保存され、外部には送られない。

## 導入方法

### 必要なもの

- サーバーを動かす1台(Windows / macOS / Linux)
- Node.js 24 以上(組み込みのSQLiteを使うため、古い版では動かない)
- ブラウザー(Edge / Chrome など)

### 手順

1. このフォルダをサーバーにするPCに置く。

2. ターミナル(Windows では PowerShell)でこのフォルダを開き、次を順に実行する。

   ```
   npm install
   npm run build
   npm start
   ```

   `npm install` と `npm run build` は、最初の1回と更新したときだけでよい。
   Windows では、3つをまとめて行う `.\start.ps1` も使える。

3. ブラウザーで開く。

   - サーバーのPC: `http://localhost:3002`
   - 同じネットワークの別PC: `http://<サーバーのPCの名前またはIP>:3002`

   別PCから開けないときは、サーバーのPCのファイアウォールでポート 3002 の受信が許可されているか確認する。

初回起動時は、サンプルのメンバー・案件・タスクが入った状態から始まる。不要なものは画面から削除する。

止めるときは、起動したターミナルで Ctrl+C を押す。

### 合言葉で保護する

既定では、アドレスにつながる人は誰でも読み書きできる。使う人を限りたいときは、環境変数 `TEAM_FOCUS_PASSWORD` に合言葉を設定して起動する。

```powershell
# Windows (PowerShell)
$env:TEAM_FOCUS_PASSWORD = "ここに合言葉"
npm start
```

```sh
# macOS / Linux
TEAM_FOCUS_PASSWORD="ここに合言葉" npm start
```

設定すると、初めて開いたブラウザーで合言葉を聞かれる。一度入力すれば、そのブラウザーでは約半年間聞かれない。合言葉を変えると、全員が入力し直しになる。

合言葉はチーム全員で共通の1つで、利用者ごとのアカウントや権限は無い。

### 設定

既定値のままなら設定不要。変える場合は、起動前に環境変数で指定する。

| 変数 | 既定値 | 内容 |
|---|---|---|
| `TEAM_FOCUS_PORT` | `3002` | ポート(`PORT` でも指定できる) |
| `TEAM_FOCUS_HOST` | `0.0.0.0` | 待ち受けるアドレス。`127.0.0.1` にすると、サーバーのPCからしか開けなくなる |
| `TEAM_FOCUS_PASSWORD` | (なし) | 合言葉。上の「合言葉で保護する」を参照 |
| `TEAM_FOCUS_DB` | `server/team-focus.db` | データの保存先 |

### データの保存先とバックアップ

メンバー・案件・タスクは、すべて `server/team-focus.db`(SQLite)の1ファイルに入る。バックアップは、サーバーを止めてからこのファイルをコピーする。

このファイルを消して起動すると、サンプルが入った状態から始まる。

### インターネット越しに使う場合

社内や家庭内のネットワークで使うことを想定している。インターネットから開けるようにする場合は、次を必ず行う。

- `TEAM_FOCUS_PASSWORD` に、推測されにくい長い合言葉を設定する。
- HTTPS にする(リバースプロキシやトンネルサービスなどを前段に置く)。HTTP のままでは、合言葉や内容が通信経路で読まれうる。

## 使い方

### 画面の見かた

- **ヘッダー(上)**: 検索欄。タスク名・案件名・担当者名で絞り込む。
- **ナビゲーションバー(左)**: 画面の切り替え、タスクの追加、担当者の絞り込み、メンバーと案件の一覧。ロゴの下のボタンで隠して、本文を横いっぱいに広げられる。
- **本文(右)**: タスクの一覧、またはチーム稼働の表。

ナビゲーションバーで切り替える画面は次の3つ。

| 画面 | 内容 |
|---|---|
| 今日の作業 | 期限が今日まで(期限切れを含む)の未完了タスク。期限なしのタスクは出ない |
| すべてのタスク | すべての未完了タスク |
| チーム稼働 | メンバーごとの稼働と空きを見る表 |

他のPCでの変更は、30秒ごとと画面に戻ったときに自動で反映される。

### 最初にやること

1. **メンバーを登録する**: ナビゲーションバーの「メンバー」の歯車(またはチーム稼働の表の「メンバー」の横の＋)から、名前と色を登録する。
2. **案件を登録する**: ナビゲーションバーの「案件」の横の＋から、案件名・担当メンバー・進捗・開始日・期限を入れる。開始日と期限の両方を入れた案件だけが、チーム稼働の表で期間のバーになる。
3. **タスクを登録する**: 下の「タスクを追加する」を参照。

### タスクを追加する

- **1件ずつ**: ナビゲーションバーの「タスク追加」。案件・タスク名・担当者のほか、開始日・期限・繰り返し・参照リンク・ファイルのリンクを任意で入れる。案件に属さないものは「案件外」にする。
- **Excelからまとめて**: ナビゲーションバーの「Excel取込」。1枚目のシートを読み込む。見出し行に「タスク名」(必須)の列があればよく、進捗・優先度・開始日・期限・繰り返し・参照リンク・ファイルのリンク・担当者の列も置ける(列の順番は自由)。取り込み画面からテンプレートをダウンロードできる。一度に登録できるのは1000件まで。
- **チーム稼働の表から**: 案件名の横の、リストに＋が付いたボタン。その案件(と、メンバーの下の案件ならそのメンバー)が最初から入る。

参照リンクとファイルのリンクには、`http://` または `https://` で始まるURLを入れる(チャットのメッセージ、クラウド上のファイルなど)。

### タスクを進める

- 一覧は、期限なしを先頭に、あとは期限が近い順に並ぶ。
- チェックを付けると完了になる。直後に出る「元に戻す」で取り消せる。
- 進捗(未着手・進行中・回答待ち・完了)と優先度(高・中・低)は、行のバッジを押して変える。
- 担当者は、行の担当者アイコンを押して変える。
- タスク名を押すと、内容を編集できる。
- 繰り返し(毎日・平日・毎週・毎月)を設定したタスクは、完了にすると次回分が1件自動で作られる。
- 「完了も表示」で、完了したタスクも一覧に出せる。

### 自分のタスクだけ見る

ナビゲーションバーの「担当」の選択、またはメンバーの一覧から名前を押すと、その人のタスクだけに絞り込む。もう一度押すと解除する。絞り込みはブラウザーごとに覚える。

### 案件を見る・変える

- ナビゲーションバーの案件名を押すと、その案件の概要とタスク一覧が開く。ここから進捗の変更、編集、削除、タスクの追加、Excel取込ができる。
- 案件を削除するときは、タスクを「案件外」に移すか、一緒に削除するかを選ぶ。
- 完了した案件は一覧から隠れる。「案件」の横のチェックのボタンで表示できる。

### チーム稼働の表

メンバーごとに、いつ何を抱えているか、どこが空いているかを見る表。見出しの横のスイッチで表示を切り替える。

| 表示 | 内容 |
|---|---|
| タスク単位 | メンバーごとに、その日に抱えている未完了タスクの件数(平日のみ) |
| 案件単位・人集約 | メンバーごとに、週ごとの担当案件数と、担当案件の期間 |
| 案件単位・案件集約 | 未完了の案件ごとに、担当メンバーと期間 |

色は、緑が空き、青が濃いほど件数が多い。右端の「空き」は、今日以降の表示期間で担当が無い日数(または週数)。

表でできること:

- **表示期間を変える**: 右上の前後のボタンと期間の選択。案件単位では、上のミニマップの枠をドラッグするか、表をつかんで左右に動かしてもよい。
- **メンバーを開閉する**: メンバー名の左の矢印。見出し「メンバー」の横のボタンで、全員をまとめて開閉する。
- **名前の列の幅を変える**: 見出しの右端のつまみをドラッグする。ダブルクリックで元の幅に戻る。
- **メンバーを追加する**: 見出し「メンバー」の横の＋。
- **案件を追加する**: メンバー名の横の＋。その人が担当に入った状態で登録画面が開く。
- **案件を編集する**: 案件名を押す。
- **案件のタスクを見る**: 案件名の横の矢印と数字(未完了タスクの件数)を押すと、その案件のタスクが下に展開される。
- **案件にタスクを追加する**: 案件名の横の、リストに＋が付いたボタン。
- **未割当の案件の担当を決める**: 担当がいない案件の、人のアイコン(案件集約では「担当なし」)を押すと、担当候補が並ぶ。その案件の期間に空いている週が多いメンバーから順に、空きの週数・重なる案件数・週ごとの埋まり具合を表示する。メンバーを押すと担当になる。
- **メンバーのタスク一覧へ移る**: メンバー名を押す。

稼働の基準は件数だけで、タスクや案件の重さは見ていない。

## 開発

画面を書き換えながら確かめるときは、APIサーバーと画面を別々に起動する。

```
npm run server   # APIサーバー(ポート3002)
npm run dev      # 画面(Vite、ポート5174)。/api はAPIサーバーへ中継される
```

`http://localhost:5174` を開く。Windows では `.\start-dev.ps1` で両方をバックグラウンドで起動できる(止めるときはタスクマネージャーで `node.exe` を終了する)。

| パス | 内容 |
|---|---|
| `server/index.js` | API (Express)。入力値の検証、合言葉の確認、ビルドした画面の配信 |
| `server/db.js` | SQLite。列の追加と初期データもここ |
| `shared/constants.js` | サーバーと画面で共通の定数(進捗・優先度・繰り返しなど) |
| `src/App.tsx` | 画面全体の状態と操作 |
| `src/components/` | 画面部品(タスク行、各モーダル、チーム稼働など) |
| `src/lib/` | API呼び出し、日付計算、表示用の定数 |
